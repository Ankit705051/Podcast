# NEXUS: The Awakening

An original, anime-fantasy-inspired college technology festival concept. Built with React, TypeScript, Vite, React Three Fiber, Three.js, GSAP, Framer Motion, Tailwind CSS, React Router, Drei, and Lucide React. The floating castle, portal, islands, clouds, and event-map landmarks are rendered from original procedural 3D geometry; there are no copied franchise assets or pre-rendered video scenes.

## Run locally

```sh
npm install
npm run dev
```

Production build:

```sh
npm run build
npm run preview
```

## Before publishing

This is an editable festival concept, not a live registration or event site. Replace the sample institute, dates, schedule, prices, sponsors, team names, and social links in `src/data.ts` and `src/App.tsx`. The pass-interest form validates input and displays a local demo confirmation; it does not transmit or store personal details. Connect it to a registration service before accepting passes. Confirm all event details, eligibility, accessibility, privacy terms, and pricing before launch.
